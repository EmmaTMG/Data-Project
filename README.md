# Data-Project
This project showcases a full end to end data workflow for analysing product and category performance, using ETL processing, data modelling, and interactive BI reporting. The featured dashboard provides:
•	Key annual KPIs including total sales, YoY change, and transaction volume
•	Category contribution analysis, showing that the top three product groups drive over 78% of total sales
•	Monthly sales trends comparing current year and prior year performance
•	Clear commercial insights to support product, pricing, and operational decisions
The report demonstrates strong capability in Power BI, data storytelling, and analytics for product performance
